# מיילים

תבניות HTML לדיוור. הן לא נבנות עם האתר — הן נשלחות דרך Resend.

| קובץ | מה זה | מצב |
|---|---|---|
| מוטמע ב־`api/subscribe.js` | מייל האישור (אישור כפול) | מחכה לדומיין |
| `mikhtav-peticha.html` | מייל הפתיחה, נשלח אחרי האישור | מחכה לדומיין |

## למה הכל מחכה לדומיין

Resend שולח רק מדומיין מאומת. `vercel.app` אינו שלנו ולכן אי אפשר לשלוח ממנו.
עד אז הטופס באתר **כן** עובד: הכתובת נשמרת ברשימה במצב "ממתין לאישור", והמבקר
מקבל הודעה כנה שהדיוור ייפתח בקרוב.

## מה צריך לעשות ביום שהדומיין קיים

1. לאמת את הדומיין ב־Resend ולהוסיף את רשומות ה־DNS שהוא נותן (SPF, DKIM, DMARC).
2. להגדיר ב־Vercel: `MAIL_FROM` (למשל `aran@example.co.il`), `SITE_URL`, ו־`CONFIRM_SECRET` (מחרוזת אקראית ארוכה).
3. לשלוח מייל אישור לכל מי שנרשם בינתיים ועדיין מסומן כלא־רשום.
4. להחליף ב־`mikhtav-peticha.html` את `{{SITE}}`, `{{UNSUBSCRIBE}}` ו־`{{ADDRESS}}`.

## דרישות שאסור להוריד מהתבניות

חוק הספאם מחייב שכל הודעת פרסומת תישא את שם המפרסם וכתובתו, ותציע דרך להסרה.
הבלוק התחתון בתבנית הוא בדיוק זה — לא לקצץ אותו כדי "לנקות" את העיצוב.

הסכמה נאספת פעמיים: תיבת סימון שאינה מסומנת מראש בטופס, ולחיצה על קישור חתום במייל.
רק אחרי השנייה איש הקשר נהיה רשום.
