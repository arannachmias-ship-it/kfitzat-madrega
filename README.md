# קפיצת מדרגה

אתר הלימוד וההרצאות. Astro + MDX, אתר סטטי, בלי בסיס נתונים ובלי שרת.

## להריץ מקומית

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # בונה לתיקיית dist
```

## איך מוסיפים שיעור

1. פותחים קובץ חדש ב-`src/content/maslul/<slug>.mdx`.
   ה-slug חייב להיות זהה ל-slug שמופיע ב-`src/data/track.ts`, אחרת השיעור לא יתחבר למפה.
2. ממלאים את הכותרת (frontmatter):

```yaml
---
stage: 1              # 0 עד 4
order: 2              # המיקום בתוך השלב
title: "כותרת השיעור"
kicker: "הכאב, שורה אחת. זה מה שמופיע גם בתיאור לגוגל ובכרטיס בעמוד הבית."
goal: "מה תדעו בסוף. משפט אחד, מדיד."
readingTime: 8
author: "ארן נחמיאס"   # או "מתי מצוינים"
interactive: false
published: true       # false = עדיין לא באוויר, יופיע במפה כ"בקרוב"
date: 2026-08-25
---
```

3. כותבים את הגוף לפי שמונת הבלוקים. שלושה מהם הם `div` עם class:

- `<div class="demo">` ההדגמה על הכלי. **זה הבלוק היחיד שמתיישן, ולכן היחיד שמתחזקים.**
- `<div class="task">` התרגיל של חמש עשרה דקות.
- `<div class="boundary">` "עד כאן לבד". הגבול הכן, ומנגנון ההמרה. **בלוק אחד בלבד בכל שיעור, בסוף** — הוא כהה, ושניים כאלה מבטלים זה את זה.
- `<div class="note">` הערת שוליים: הסתייגות, מצב רגולטורי, כל מה שנכון לומר ולא נכון להבליט.

ציטוט־מפתח (`>` בתחילת שורה) הוא המשפט היחיד שהקוראת אמורה לזכור אחרי שסגרה את העמוד. אחד לשיעור, לא יותר.

פרומפטים נכתבים בגוש קוד רגיל (שלושה גרשים). הם נהיים RTL אוטומטית.
**אסור להשאיר שורה ריקה בתוך גוש קוד ב-MDX** — זה שובר את הבנייה.

## איך מוסיפים שיעור למפה בלי לכתוב אותו

`src/data/track.ts` מחזיק את כל 29 השיעורים. שיעור שאין לו קובץ MDX מופיע במסלול
כ"בקרוב" ולא ניתן ללחיצה. ככה היקף התוכנית נראה מהיום הראשון.

## מערכת העיצוב

הכל ב-`src/styles/global.css`, למעלה, כמשתני CSS.

- **ציטרון (`--accent`) מסמן רק דבר אחד: איפה ללחוץ.** לא כותרות, לא קישוט.
  ברגע שהוא מופיע במקום נוסף, הוא מפסיק לומר משהו.
- **פינות: 6 לכפתורים ולשדות, 10 לכרטיסים ולמדיה.** בלי חריגות.
- **בלי `letter-spacing` על עברית.** אף פעם. זה שובר את זרימת האותיות.
- **גובה שורה 1.7 בגוף, גוף לא קטן מ-16px.**
- **מאפייני CSS לוגיים בלבד** (`margin-inline`, `border-inline-start`) ולא `left`/`right`,
  כדי שה-RTL יעבוד מעצמו.
